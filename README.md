# SpyPanel

Custom hosting-panel project designed for a CodeSandbox-friendly Node.js workflow.

## Run

```bash
npm install
npm start
```

Default port: `6767`

## Installer

```bash
npm run install-panel
```

Linux one-click installer:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yoshidaranimahato-collab/SpyPanel-2/main/install.sh)
```

> The one-click command requires a public GitHub repository and a Linux environment with Git, Node.js and curl.

## Current scope

This starter contains the project foundation and dashboard UI. Real server/node orchestration is intentionally not included yet.
